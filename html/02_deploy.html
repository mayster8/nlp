2.2.5. リスト内包表記（発展）#

リストを作るとき、for文を1行で書ける便利な方法です。

nums = [1, 2, 3]

# 普通のfor文で2倍のリストを作る
doubled = []
for n in nums:
    doubled.append(n * 2)

# 内包表記を使うと1行で書ける
doubled_comp = [n * 2 for n in nums]

print("2倍:", doubled)
print("2倍（内包表記）:", doubled_comp)
出力例を表示する 
2倍: [2, 4, 6]
2倍（内包表記）: [2, 4, 6]

2.3. spaCy / GiNZA の導入#

2.3.1. spaCy / GiNZA とは？#

2.3.1.1. spaCy（スペイシー） とは#

  • 自然言語処理（NLP）のための Python ライブラリ

  • 高速かつ実用的な処理が可能で、研究よりも「実務やアプリ開発」で広く使われている

  • 主な機能：

    • トークン化（文を単語に分割）

    • 品詞タグ付け（名詞、動詞、形容詞など）

    • 依存構造解析（主語・述語・目的語の関係を解析）

    • 固有表現抽出（人名、地名、日付など）

英語を中心に多数の言語モデルが提供されており、簡単に導入できるのが強み

2.3.1.2. GiNZA（ギンザ） とは#

  • spaCy の日本語用ライブラリ／言語モデル

  • 日本語は英語と異なり「単語の区切りが曖昧」なので、形態素解析が必要

  • GiNZA は日本語文章を対象にした 高精度の形態素解析・依存構造解析 を実現

  • 主な特徴：

    • 名詞・動詞などの品詞情報を取得可能

    • 活用形を原形（lemma）に変換

    • 文の依存関係を解析して構造を明らかにする

2.3.1.3. spaCy と GiNZA の関係#

  • spaCy：自然言語処理の「本体」（フレームワーク）

  • GiNZA：その中で使う「日本語用の言語モデル」

  • イメージ：

    • spaCy = 車の本体

    • GiNZA = 日本語を走らせるための専用エンジン

2.3.2. インストール#

!pip -q install spacy ginza ja-ginza

2.3.3. 日本語モデルをロード#

import spacy
nlp = spacy.load("ja_ginza")

doc = nlp("私は昨日、東京で美味しいラーメンを食べた。")

# 形態素を抽出してリストに追加
tokens = []
for t in doc:
    tokens.append(t.text)

print(tokens)  # トークン化の確認

出力例：

['私', 'は', '昨日', '、', '東京', 'で', '美味しい', 'ラーメン', 'を', '食べ', 'た', '。']

2.3.4. 形態素解析の詳細表示#

for token in doc:
    print(token.text, token.lemma_, token.pos_, token.dep_)

出力例：

私       私       PRON   nsubj
昨日     昨日     NOUN   obl
東京     東京     PROPN  obl
美味しい 美味しい ADJ    amod
ラーメン ラーメン NOUN   obj
食べ     食べ     VERB   ROOT
た       た       AUX    aux
。       。       PUNCT  punct

2.3.4.1. 各列の意味#

  1. token.text
    → 文に現れた形（表層形）
    例：「私」「昨日」「東京」

  2. token.lemma_
    → 原形（辞書形）
    例：「食べた」→「食べ」、「美味しかった」→「美味しい」

  3. token.pos_
    → 品詞（大分類）

    • PRON = 代名詞

    • NOUN = 名詞

    • PROPN = 固有名詞

    • ADJ = 形容詞

    • VERB = 動詞

    • AUX = 助動詞

    • PUNCT = 記号

  4. token.dep_
    → 文中での役割（係り受け関係）

    • nsubj = 主語

    • obl = 修飾語（副詞的）

    • amod = 形容詞による修飾

    • obj = 目的語

    • ROOT = 文の中心（述語）

    • aux = 助動詞

    • punct = 句読点

2.3.4.2. 出力の解釈例#

  • 私 (PRON, nsubj) → 主語（誰が？）

  • 昨日 (NOUN, obl) → 修飾語（いつ？）

  • 東京 (PROPN, obl) → 修飾語（どこで？）

  • 美味しい (ADJ, amod) → 「ラーメン」を修飾する形容詞

  • ラーメン (NOUN, obj) → 目的語（何を？）

  • 食べ (VERB, ROOT) → 文の中心（述語）

  • た (AUX, aux) → 助動詞（過去形を表す）

  • 。 (PUNCT, punct) → 句点

2.3.4.3. 名詞だけを抽出する#

text = "自然言語処理の授業で、PythonとGiNZAを学びます。"
doc = nlp(text)

nouns = []  # 名詞を入れるリスト
for t in doc:
    if t.pos_ == "NOUN" or t.pos_ == "PROPN":
        nouns.append(t.lemma_)

print(nouns)

2.6.3. 課題3#

  • 以下の関数は「名詞」「固有名詞」だけをリストで取り出すプログラムです。

def extract_nouns(text):
    doc = nlp(text)
    words = []
    for t in doc:
        if t.pos_ in ("NOUN", "PROPN"):
            words.append(t.text)
    return words

sentence = "自然言語処理の授業で、PythonとGiNZAを学びます。"
print(extract_nouns(sentence))

  • 上記を修正して、 「動詞」 のみをリストで取り出してください
